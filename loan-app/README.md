# 융자취급신청관리 (UGSLT08004M01)

TO-BE 화면설계서를 바탕으로 만든 단일 페이지 웹 화면입니다. 서버 없이 `index.html`을 브라우저로 열면 동작합니다.

## 기능
- **입력/저장**: 하단 상세 영역(사업장정보, 신청정보)에 입력 후 `저장`. 신규는 `SN-YYYY-NNNNNN` 번호가 자동 채번됩니다.
- **조회**: 신청번호(연도·일련번호), 구역명, 신청인, 신청일자 기간으로 검색. 목록 행을 클릭하면 상세에 불러와 수정·삭제할 수 있습니다.
- **엑셀다운로드**: 현재 조회조건에 맞는 목록을 `.xlsx`로 내려받습니다(SheetJS를 `lib/`에 포함해 폐쇄망에서도 동작, 로드 실패 시 CSV로 대체).

## 참고
- 데이터는 브라우저 `localStorage`에 저장됩니다(PC·브라우저별). 실제 운영에는 서버 API/DB 연동이 필요합니다.
- 첨부파일은 파일명만 기록합니다.
